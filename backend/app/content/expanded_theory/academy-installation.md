# Установка Python

## Интерпретатор, команда и файл
Python-файл является текстом программы, а интерпретатор — приложением, которое этот текст выполняет. Расширение `.py` помогает инструментам распознать файл, но не устанавливает Python. Команда запуска выбирает конкретный интерпретатор, затем передаёт ему путь к файлу и дополнительные аргументы. Если на компьютере несколько установок, важно выяснить, какая выбрана именно сейчас.

Имя команды зависит от системы и способа установки. На Windows часто используют launcher `py`, в Unix-подобной системе — `python3`; в активированном окружении доступна его команда `python`. Не определяйте версию по значку редактора. Проверьте команду `--version`, а внутри программы — `sys.version_info` и `sys.executable`. Это наблюдение за реальным процессом, а не предположение по имени папки.

При запуске из терминала текущий каталог и каталог файла могут различаться. Относительный путь интерпретируется относительно текущего рабочего каталога. Поэтому сообщение «файл не найден» не доказывает отсутствие файла вообще: сначала проверьте, где выполняется команда и какой путь ей передан.

## Зачем проекту отдельное окружение
Виртуальное окружение хранит собственный набор установленных пакетов и связывает его с определённой установкой Python. Оно помогает двум проектам использовать разные версии одной зависимости без постоянной переустановки пакетов. При этом это не контейнер безопасности: программа сохраняет обычные права пользователя операционной системы.

Активация изменяет окружение текущей оболочки, прежде всего выбор команды интерпретатора. Она не превращает все открытые терминалы в одно окружение и не переключает автоматически настройки редактора. Если пакет установлен, но импорт не находится, сравните интерпретатор установки и интерпретатор запуска. Команда `python -m pip` явно связывает `pip` с выбранным Python.

Папку окружения обычно не включают в Git: её можно восстановить по версии Python и описанию зависимостей. Хранят исходники и файлы требований, а не тысячи локальных бинарных файлов. При переносе проекта создают новое окружение на целевой системе, поскольку абсолютные пути и бинарные расширения могут отличаться.

## Три разных места выполнения
Терминал принимает команды операционной системы. Интерактивный интерпретатор принимает выражения и команды Python. Редактор позволяет сохранить файл, который затем выполнит выбранный runtime. Ошибка «python не определено» внутри интерпретатора часто означает, что команду оболочки ввели в неверное место. Смотрите на приглашение и контекст ввода.

Браузерная учебная среда может исполнять Python в WebAssembly, а серверная — в отдельном процессе или контейнере. Это разные среды с разными возможностями: потоки, файлы, сеть и доступные пакеты нельзя считать одинаковыми автоматически. Для задачи о системных процессах нужен предусмотренный серверный исполнитель; локальная установка не меняет возможности открытой страницы.

При проверке установки начните с маленькой программы, печатающей понятную подпись и основную версию Python. Не печатайте полный список переменных окружения: он не требуется для проверки и способен раскрыть секреты. После успешного запуска настройте тот же интерпретатор в редакторе и убедитесь, что установка пакета относится к нему.
