# Лямбда-функции

## Функция как передаваемое значение
Функцию можно передать другой функции как аргумент. В сортировке параметр `key` получает действие, которое вычисляет сравниваемый ключ для каждого элемента. Нужно передать сам вызываемый объект, а не результат его немедленного вызова. Скобки после имени меняют стадию выполнения: вместо будущего действия вы получите уже вычисленное значение.

`lambda` создаёт небольшую функцию, тело которой состоит из выражения. Она удобна рядом с местом использования, когда смысл прост и не требует отдельного устойчивого имени. Это не особый режим ускорения и не замена всем обычным функциям. Сложная вложенная лямбда часто хуже читается и диагностируется, чем короткая функция с понятным названием.

Лямбда также использует окружающие привязки по правилам области видимости. Она не замораживает автоматически все внешние значения при создании. Если несколько функций создаются в цикле и используют одну изменяющуюся привязку, результат может удивить. Сначала поймите модель замыкания, затем выбирайте явную передачу параметра или фиксирование значения по нужному контракту.

## Составной ключ задаёт приоритеты
Кортеж в качестве ключа сортировки позволяет перечислить критерии по важности. Сначала сравнивается первая часть, при равенстве — следующая. Для слов это может быть длина и затем текст. Если сравнивать только длину, элементы равной длины сохранят относительный порядок благодаря стабильности сортировки, но алфавитный порядок сам по себе не появится.

Убедитесь, что соответствующие части ключей сравнимы. Смесь `None`, строк и чисел в одном критерии может привести к ошибке. Для отсутствующего значения определите отдельный явный порядок, например признак отсутствия вместе с подготовленным значением. Не подменяйте отсутствие случайным числом, которое может совпасть с настоящими данными.

`reverse` меняет направление всей сортировки. Если одному критерию нужен возрастающий порядок, а другому убывающий, продумайте ключ или последовательность стабильных сортировок. Не рассчитывайте, что общий флаг автоматически выражает разные направления для частей кортежа. Проверьте несколько элементов с равным первым критерием.

## Ключ не должен скрывать изменения
Функция ключа должна понятно извлекать характеристику элемента. Не меняйте в ней исходные данные и не обращайтесь к внешнему сервису без реальной необходимости: сортировка становится трудной для объяснения и проверки. Если вычисление характеристики дорогое, сначала подготовьте данные отдельным шагом и определите политику ошибок.

Различайте `sorted`, возвращающий новый список, и изменение исходного списка методом `sort`. Лямбда не выбирает между этими вариантами; она только формирует ключ. Можно получить правильный порядок результата и одновременно нарушить требование сохранить исходные данные, если выбрана неподходящая операция контейнера.

Полезный набор проверки включает пустой список, один элемент, несколько одинаковых ключей и данные, где второй критерий действительно меняет порядок. Сначала предскажите ключ каждого элемента вручную, затем итоговую последовательность. Так становится видно, что программа сортирует именно по выбранному контракту, а не по случайному первоначальному расположению.
