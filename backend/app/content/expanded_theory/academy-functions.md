# Функции

## Объявление, вызов и результат
Оператор `def` создаёт функцию и связывает её с именем, но не выполняет тело как обычную последовательность команд прямо сейчас. Тело начинает работать при вызове. Сначала вычисляются аргументы вызова, затем они связываются с параметрами нового выполнения функции. Поэтому один и тот же текст функции можно применять к разным данным без копирования строк алгоритма.

Параметр — имя внутри определения, аргумент — значение, переданное конкретным вызовом. Необязательно называть внешнюю переменную так же, как параметр. Связь устанавливается по правилам вызова, а не по совпадению имён. Для чтения программы полезно отдельно выписать, какое значение получает каждый параметр и что возвращается вызывающему коду.

Каждый вызов имеет собственные локальные привязки. Значение из предыдущего вызова не становится автоматически начальным состоянием следующего. Если функции нужно помнить что-либо между вызовами, это должно следовать из явной конструкции, например переданного объекта или замыкания, а не из предположения о «памяти» локальной переменной.

## Возврат позволяет соединять действия
`return` передаёт значение в место вызова и завершает текущую функцию. Вызов `print` только показывает значение и обычно возвращает `None`. Если функция печатает число, это не значит, что её вызывающий код получает напечатанное число. Разделяйте функцию вычисления и внешний вывод, когда результат понадобится следующему действию или тесту.

Вложенные вызовы читаются изнутри наружу. Сначала выполняется внутренний вызов, его возвращённое значение становится аргументом внешнего. Можно переписать выражение через промежуточную переменную, не меняя смысл: сначала получить результат одного шага, затем передать дальше. Такой вариант полезен при отладке и при длинной композиции, где одна строка скрывает слишком много действий.

Если выполнение дошло до конца тела без `return`, функция возвращает `None`. Не добавляйте `return print(...)` ради удобства: результатом останется то, что вернул `print`. Проверьте контракт явно: какой тип значения получает вызывающий код и может ли он использовать его в следующем вычислении.

## Параметры по умолчанию и побочные эффекты
Значение параметра по умолчанию создаётся при выполнении определения функции. Поэтому изменяемый список в таком параметре способен сохранить изменения между вызовами. Если нужен новый контейнер для каждого вызова, используйте `None` как маркер и создайте список внутри. Это отличается от обычной локальной переменной, которая создаётся при каждом выполнении тела.

Функция может вернуть результат и при этом изменить переданный объект. Такие побочные эффекты нужно делать понятными по назначению функции. Если вызывающий код ожидает новое значение без изменения исходного, незаметный `append` в переданном списке создаст ошибку, которую трудно найти по самому результату. Для чистого вычисления удобнее возвращать новый объект или документировать изменение.

Проверяйте функцию отдельно от ввода и вывода. Передайте обычное значение, ноль, пустую коллекцию или иной предусмотренный граничный случай. Затем используйте результат в другом вызове. Если это невозможно без чтения напечатанного текста, вероятно, вычисление и представление результата пока смешаны.
