# Technology icons

`technology-icons.json` contains the unchanged SVG path data of 22 icons from
[Simple Icons 16.35.0](https://github.com/simple-icons/simple-icons/tree/16.35.0/icons).
They render as local inline SVGs and require no third-party requests at runtime.

Brand names and marks remain the property of their respective owners; see the
[upstream disclaimer](https://github.com/simple-icons/simple-icons/blob/16.35.0/DISCLAIMER.md).

Python uses the existing `public/python-logo.svg`. Generic browser APIs and tools
without a supplied brand mark use the project's existing Lucide icons.
